# Compatibility fixtures

These fixtures preserve the behavior before the 2026-10-28 source reorganization,
at Git revision `c428302ce515e95a14643871ce2b7fbb59bf2682`.

`ui_snapshot_hashes.json` records SHA-256 hashes of all 45 PBM frames generated
by the original `test_ui` executable, using the checked-out u8g2 dependency and
the host firmware version `1.2.3-host`. The host runner removes the corresponding
generated frames before testing and requires exact matches after rendering.

The five files in `storage/` were generated by compiling `test_storage_compat.c`
with that revision's original `app_state.c`, profile implementations and host
NVS substitutes. They were not recorded from the refactored serializer:

- `mixed-v3.bin`: IR bindings, four keyboard presets, custom modifiers, sparse
  text with punctuation/spaces, both mouse modes, peers/identities, and Wi-Fi.
- `edited-v3.bin`: rename, profile deletion/reordering and changed text. It is
  checked again after failed writes to verify durable data remains unchanged.
- `v1-to-v3.bin` and `v2-to-v3.bin`: migration retaining legacy Bluetooth bonds.
- `legacy-ir-to-v3.bin`: migration of all 32 legacy IR recordings.

The test reads saved NVS bytes and compares them directly with these files. It
also reinitializes application state and verifies loaded data. The normal runner
only compares fixtures. The harness's `--record DIRECTORY` mode exists for
explicit baseline capture; review any fixture update as a behavior/format change.
